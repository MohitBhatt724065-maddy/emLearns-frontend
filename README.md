# emLearns Frontend

React frontend for emLearns, a neuroscience E-Learning platform with an interactive
assessment engine, performance analytics dashboard, and course catalog.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Recharts (analytics charts)
- Axios (API calls)

## Features

- Course catalog and course details
- Learning interface and "My Learning" page
- Assessments (list + quiz-taking page)
- Student dashboard and performance analytics
- Authentication pages (login, register, forgot password)

## Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/MohitBhatt724065-maddy/emLearns-frontend.git
cd emLearns-frontend
npm install
npm run dev
```

App runs at `http://localhost:3000`.
